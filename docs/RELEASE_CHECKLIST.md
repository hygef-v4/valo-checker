# ValoCheck — Release Checklist

Work through this list before every store release.

## Code health

- [ ] `flutter analyze` — zero issues.
- [ ] `flutter test` — all tests pass.
- [ ] CI green on the release commit.
- [ ] No fabricated/placeholder data paths added — missing data must render an honest "unavailable" state (see `widgets/common/data_unavailable.dart`).

## Versioning

- [ ] Bump `version:` in `mobile/pubspec.yaml` — build number (`+N`) must increase on every store upload.
- [ ] Tag the release commit (`git tag v1.0.0`).

## Android

- [ ] `mobile/android/key.properties` present and pointing at the real upload keystore (never committed).
- [ ] `flutter build appbundle --release` succeeds and is signed with the release key (check with `jarsigner -verify` or Play Console upload).
- [ ] Install the release APK on a physical device and verify:
  - [ ] Fresh login works end-to-end (WebView → store loads).
  - [ ] Kill the app, reopen — session restores without retyping credentials.
  - [ ] Airplane mode → pull-to-refresh shows an error but does NOT log you out.
  - [ ] After ~1 hour (token expiry), "Log in" completes with one tap (SSO cookie).
  - [ ] Match details tabs on an old/limited match show "unavailable" states, never invented numbers.
- [ ] App name shows as **ValoCheck** on the launcher.
- [x] App icon set — shield+check mark generated by `tool/generate_icon.dart`; to tweak it, edit that file, run `flutter test tool/generate_icon.dart`, then `dart run flutter_launcher_icons`.

## iOS (when shipping to the App Store)

- [ ] `CFBundleDisplayName` = ValoCheck (done), icons in `Assets.xcassets`.
- [ ] Set the signing team in Xcode; archive with a distribution certificate.

## Store listing

- [ ] Privacy policy URL (required — app has login). Content: credentials entered only on Riot's page; tokens in device keystore; no third-party servers.
- [ ] "Unofficial — not endorsed by Riot Games" disclaimer in the store description (it is already on the in-app login screen).
- [ ] Screenshots from a real account.
- [ ] Data-safety form: account tokens stored on device, no data shared.

## Known operational risks

- Riot's unofficial client APIs can change without notice — watch for spikes in "Could not load data" after Valorant patches. The Riot client version is fetched at runtime from valorant-api.com (hardcoded fallback in `riot_api_client.dart` — keep it roughly current when touching that file).
- valorant-api.com (metadata CDN) being down degrades names/images but must not crash the app.
